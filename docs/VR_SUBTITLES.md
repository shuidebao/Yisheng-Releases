## 已实现与验证

- `app/vr_overlay.py`：可选独立子进程；默认不启动、不导入 OpenVR/.NET。当前字幕以本地管道传递，只保留最新状态；无变化时仅处理运行时事件，不重复绘图。独立写入线程与有界队列让响应预算同时覆盖管道写入等待；停用/主程序退出优先通过 EOF 清理，超时仅终止自身创建的子进程。若无法确认退出，保留进程引用、阻止重复开启并允许重试关闭。SteamVR 异步图像失败事件会结束连接并报告错误。
- `DesktopBridge`：同一当前句快照同时供桌面与 VR 使用；清空同步，VR 不依赖原生迷你窗口可见。保留 API/识别/音频行为。
- 设置界面：独立开关、大小、上下位置、距离、不透明度、原文与重置；中英提示、异常恢复与启动中禁重复操作。增加固定测试字幕（最长 5 秒），只在连接成功后可用，不启动录音或调用 API；结束后恢复当前一句，新字幕/清空可提前结束。区分等待字幕、测试字幕、当前一句；状态表示显示进程确认接收，不代替头显可见性验证。轮询暂时失败会保留上次连接状态并重试，迟到响应不能覆盖后续操作。显示参数只用于本次会话，每次重启默认关闭。
- 使用已有 Windows 字体绘制；中英日韩图像已检查。长句缩小到最小可读字号后显示省略号，不保证无限长度完整显示；不恢复历史队列。
- Python 完整回归 195 项通过；显式移除 site-packages 后，轻量回归 179 通过/16 跳过；五组前端检查通过。新增管道阻塞、响应超时、关闭失败保留引用/重试、无效确认响应、测试字幕恢复/取消和异步图像失败回归。真实 WebView/原生迷你字幕与正常退出验证通过，包含测试字幕约 5 秒自动结束、清空取消测试、保持本地翻译模式和关闭主窗口时仍活动的 VR 子进程清理；VR 成功连接路径使用明确的模拟子进程，不能算头显内显示验收。
- 本轮证据 `.release-build/vr-20261010-hardening/`：`blocked-pipe-before.json` 为修复前关闭卡住的复现；`tests-vr-final.log`、`tests-full.log`、`tests-no-site-packages.log`、`desktop-result.json`、`desktop.log` 与 WebView 自身生成的 `desktop-webview.png` 为回归记录。
- 首版证据仍在 `.release-build/vr-20261010/`：真实检查 `native-preflight.json`、文字绘制 `render-final-*.png` 和此前桌面/单测日志。一次屏幕截图被其他前台窗口遮挡，不作布局证据；初次桌面测试脚本相对路径错误记录保留，不计作通过。

## 目标与边界

本地安装包证据：`.release-build/package-1.0.25-20261010/`。标准解包、4190 文件摘要、两轮正式启动器、VR 设置/测试字幕/清空/退出、真实无头显错误及清理、中英日韩绘制均通过；离线 Base/CPU 与本机模拟 API 回归记录为 `package-1-0-25-20261010-api-audio.json`。成功 VR 连接仍使用模拟子进程，不能代替头显验收。包 SHA-256 `4040FD72E2D3348D1B3D37E7379B6483EDD11A37D0CFB6D4E6C580CB9A9C3CEE`。

- 在 Windows PCVR 的头显视野中显示本机私人字幕，复用译声现有识别、翻译、声音采集和当前一句语义。
- 拟用 SteamVR/OpenVR 独立 Overlay，不注入 VRChat，不向游戏聊天框或 OSC 发送字幕，不同步给其他玩家。
- 只显示当前一句；续写原位更新，清空立即隐藏内容。显示与桌面字幕一致的翻译错误，避免把上一句译文误当新句结果。
- 默认免费离线；仅用户主动配置并明确同意后，可选 API 翻译才能发送识别文字，不上传语音。VR 显示端不持有 API 密钥，也不发起识别、翻译或网络请求。
- 保留现有模型、VAD、线程预算、音源选择及 API 同意/revision 边界；不恢复四句滚动字幕。
- 首版不做一体机原生版、说话人识别、按玩家位置显示、世界固定或手腕字幕，不依赖付费 Overlay 软件。
- 本地叠层不等于录屏不可见：SteamVR 镜像、录屏、直播是否捕获须分别实测。

## 已核实的接入点

`APP/Yisheng/static/app.js` 已通过桌面桥接 `update_overlay` 提交当前字幕；清空走 `clear_overlay`。

`APP/Yisheng/app/desktop.py` 的 `DesktopBridge` 保存 `_latest_subtitle`，字段为 `original`、`translation`、`meta`；`get_overlay_snapshot()` 返回副本。`_render_overlay()` 向原生桌面字幕与 VR 显示端同步同一当前句；清空也同步。

已在桥接层向 VR 显示端传递同一份最新字幕快照，不另开识别/翻译管线。VR 未启用时不初始化 VR 运行时。即使桌面字幕未显示，VR 开关也独立工作。

## 实机验收顺序（源码已准备，以下硬件步骤未完成）

1. **最小显示验证**：手动启动 SteamVR 并连接头显，开启字幕后点击「显示测试字幕（5 秒）」检查位置；再补测中英日韩固定文本。先验证游戏内可见、透明背景、头部相对定位、双眼舒适性和退出清理，不先接入语音。
2. **生命周期隔离**：独立显示进程拥有 VR 对象，使用只保留最新快照的有界状态；字幕/样式变化时才更新图像。事件处理与文字重绘分开，避免跟随头显刷新率重复绘制文字。禁止无上限队列。
3. **字幕接入**：桥接更新与清空同步到 VR；开始显示、停止显示、启动失败、运行时退出和资源释放均明确反馈。启动尚未完成时的关闭请求不得产生迟到叠层。头显/运行时断开后不自动反复重连，允许用户手动重试。
4. **基础设置**：默认关闭；在桌面设置中提供显示开关、字号、垂直位置、距离、透明度和是否显示原文。首先使用固定头部相对位置，提供恢复默认位置的入口；不抢夺游戏输入焦点。
5. **回归与实测**：保留原生桌面字幕、现有 WebView 和退出逻辑。用户已授权本地实验包供外部实测，完成下表测试后再评估正式发布；当前无 GitHub 发布授权。

依赖固定为 `openvr==2.12.1401`（BSD），使用已有 Windows System.Drawing，不增加 Pillow、Unity 或另一套推理库。已从 PyPI 下载 wheel，核对官方 SHA-256 `EF761CEF3162843A8025A7812D5E244FD94AB3A992CA8F5EF0D1B0188AD56CB3`，安装到项目自带 Python 的 site-packages；未修改全局环境。来源记录 `openvr-source.json`，Python 绑定与 Valve SDK 许可均保留在应用 `licenses/` 中。可选依赖清单为 `requirements-vr.txt`；旧安装包不因此获得此组件。

## 验收清单

| 范围 | 检查与证据 |
| --- | --- |
| 固定文本 | VRChat 前台且 SteamVR 面板关闭时可见；中英日韩、长句、换行无乱码，超长内容处理明确；转头、坐站与重置视角后可读 |
| 字幕一致性 | 新句替换、同句续写、正常重复句、清空、API 错误与桌面当前结果一致；不产生四句历史；停止显示后无残留 |
| 私人性 | 另一名玩家视角与游戏聊天框均无字幕；分别记录 SteamVR 镜像、录屏、直播捕获情况，不承诺对屏幕共享隐身 |
| 音源 | 实际头显声音输出可回采；断开/重连、默认输出切换符合现有音源策略，不自动切麦克风、不混拼新旧音源 |
| 隐私 | VR 端无外部网络发送；默认离线模式不发送识别文字或语音；API 配置与明确同意由现有路径控制，VR 开关不能改变它 |
| 异常与清理 | 无 SteamVR、无头显、初始化失败、重复启停、启动期间关闭、运行时退出、头显断开、应用关闭；无迟到/重复叠层，无新增残留线程或进程 |
| 性能 | 同一世界/场景/刷新率下比较三组：游戏单独、游戏+原同传、游戏+原同传+VR；记录 CPU/GPU 帧时间、重投影、内存及 VR 显示新增延迟，区分采集/推理与显示延迟 |
| 持续与桌面回归 | 实机连续至少 30 分钟；多次启停与正常退出；现有单测、前端测试、真实 WebView、原生迷你字幕回归通过 |

硬件确定后再约定性能阈值。没有头显实测时只能报告源码/模拟测试结果，不能宣布 VRChat 兼容或首版验收完成。
