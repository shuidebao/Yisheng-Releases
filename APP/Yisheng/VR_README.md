# VR 私人字幕（1.0.25 实验测试版）

本功能正在开发，优先面向 **Windows + SteamVR + PC 版 VRChat**，重点测试 Quest。有线或无线均以实际通过 SteamVR 为前提；Quest 一体机直接运行的 VRChat 不在本版范围。

1.0.25 是供外部测试者验证 VR 功能的实验版，尚未完成真实头显验收，不代表已确认兼容任何型号或连接软件。旧 1.0.24 安装包不含 VR 功能；测试前请确认安装的是提供给你的 1.0.25 测试包。

## 安装与首次测试

1. 退出旧版译声，双击 `YiSheng-Setup-1.0.25.exe` 安装，再通过桌面快捷方式或安装目录中的 `Yisheng.exe` 启动。安装版无需另外安装 Python 或 OpenVR 依赖。此测试包不是 GitHub 正式发布或自动更新已上线的声明。
2. 在头显中建立 PCVR 连接，并确认 SteamVR 已运行且能识别头显，再启动 PC 版 VRChat。Quest 可优先验证 Steam Link，或有线 Link 后进入 SteamVR；Air Link、Virtual Desktop 等其他连接方式也须确认游戏实际经过 SteamVR。只连接电脑或进入 Quest Link，并不等于 SteamVR 已运行。
3. 打开译声「设置 → VR 私人字幕 · 实验版」，点击「开启 VR 字幕」。未开启时不会启动 VR 显示进程。
4. 连接成功后，先点击「显示测试字幕（5 秒）」检查头显中的位置和样式。它只显示固定文字，不启动录音或调用 API；结束后恢复当前一句，没有当前字幕时隐藏。新字幕或清空会提前结束测试。先用此按钮确认叠层可见，再进行同传测试。
5. 在译声中选择正确的电脑声音输出设备，设置语言并开始同传。设备应对应 VRChat 实际播放声音的耳机或扬声器；连接头显后设备可能变化，可重新打开设置刷新。VR 中只显示当前一句，字幕大小、上下位置、距离、不透明度及是否显示原文可在同一设置区域调整。
6. 看不见字幕时先检查状态是「等待字幕」「正在显示测试字幕」还是「正在显示当前一句字幕」，再检查 SteamVR 连接和游戏是否绕过 SteamVR，或使用「恢复默认位置与样式」。这些状态表示显示进程已接受内容，实际是否可见仍需在头显中确认。
7. 测试「停止同传」后，再点击主界面的「清空记录」，检查头显中的当前句和测试字幕均消失。清空记录也会清除主界面的字幕历史，请在需要时先导出。随后重新开始同传，确认新字幕仍可显示。
8. 在 VR 设置区域点击「关闭」停用 VR 显示，确认头显叠层消失；随后正常退出译声。若提示显示进程尚未确认退出，再次点击「关闭」重试清理。关闭 VR 字幕不会停止原有同传；重新启动应用默认关闭 VR，显示设置也恢复默认。

## 建议记录的测试结果

- 固定测试字幕是否可见、是否约 5 秒后消失或恢复当前句；转头时位置是否稳定，文字是否清晰，调整位置和样式后是否生效。
- VRChat 对话能否产生当前句字幕，新句是否替换旧句；清空、关闭 VR 和退出译声后是否正确消失。字幕延迟与翻译准确性请分开记录。
- 方便时再做约 30 分钟稳定性测试，记录是否有闪烁、字幕停更、明显卡顿、位置漂移或阅读不适；不舒服时立即停止。没有做这项可以直接注明「未测」。

## 隐私与限制

- 默认免费离线，VR 显示本身不需要云服务，也不上传语音或字幕。原有可选 API 翻译只在你配置并明确同意后发送识别文字；VR 开关不会改变翻译方式。
- 字幕不写入 VRChat 聊天框，不经 OSC 发送给其他玩家。录屏、镜像或直播可能包含本地叠层，需要按实际捕获方式验证。
- 只显示当前一句；特别长的文本在最小字号下会省略显示。没有说话人定位或按玩家分别显示，电脑声音回采也可能包含音乐和其他应用的声音。
- 断开、超时或 SteamVR 退出后，需要排查连接并手动重新开启；不会自动切换音源或改用麦克风。
- 尚未验证 Quest 各连接路径、其他品牌头显、实际游戏帧时间或长时间佩戴舒适性。

## 开发环境依赖

本机项目运行时已准备固定版 `openvr==2.12.1401`，没有安装全局组件。其他开发环境可按 `requirements-vr.txt` 准备此可选依赖；应用不会在运行时自动下载。

安装版测试者无需执行本节命令。开发者使用完整 Python 环境时，可在该环境运行 `python -m pip install -r requirements-vr.txt`。自带精简 Python 不含 pip，不应直接套用此命令；重新准备或打包该运行时时，需要把依赖与许可纳入现有构建流程，完成安装包验证后再分发。源码版可继续通过本项目 `run.cmd` 启动。

第三方许可见 `licenses/Python-OpenVR.txt` 和 `licenses/Valve-OpenVR.txt`。详细验收计划位于仓库 `docs/VR_SUBTITLES.md`。
