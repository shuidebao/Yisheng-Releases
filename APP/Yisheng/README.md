# 译声 YiSheng

译声是一个 Windows 本地实时语音识别与翻译桌面软件，可监听麦克风和电脑正在播放的声音，识别中文、日语、英语或韩语，并翻译为这四种语言之一。

1.0.21 包含韩语支持，识别及翻译模型均已内置，不需要另外下载。正式版功能以对应 GitHub Release 为准。

## 使用场景

- VRChat 和其他外语游戏
- 视频、直播与播客
- 麦克风对话、会议和语言学习

## 主要功能

- 麦克风与 Windows 系统声音捕获
- 原文和目标语言翻译同步显示
- 透明置顶迷你字幕，可缩放、锁定并调整字号和颜色
- Base 识别模型随安装包提供
- Tiny、Small、Medium 识别模型可按需下载
- 中文、日语、英语、韩语互译模型随正式安装包提供
- 韩中、韩日经英语中转；不会在开始同传时临时下载翻译模型
- 自动检查更新并执行 SHA-256 完整性校验

软件不需要用户配置 OpenAI API。实时音频、识别和翻译在本机完成；联网用于可选模型下载和软件更新。

## 安装

普通用户从官方 GitHub Releases 下载最新的 `YiSheng-Setup-<版本>.exe`，双击后可以自定义安装位置。正式安装包支持 Windows 10/11 64 位。

官方发布地址：https://github.com/shuidebao/Yisheng-Releases/releases/latest

## 使用

1. 选择识别语言和翻译目标语言。
2. 选择麦克风、电脑声音或两者同时。
3. 点击“开始同传”。
4. 需要覆盖在游戏或视频上方时，点击“迷你字幕”。

韩语对话建议将识别语言明确选为“韩语”；自动识别对短句、背景音乐及多人叠音可能判断不准。韩中、韩日中转翻译可能丢失细节，不保证游戏术语或复杂句准确。

两份韩语模型新增约 293.5 MiB 磁盘占用，按所选方向加载；输出韩语使用较大的模型，因此并非零额外内存开销。原有中日英模型与参数不变。
