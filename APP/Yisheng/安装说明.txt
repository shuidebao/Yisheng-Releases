译声 · 免费本地同声传译
========================

系统要求
--------
Windows 10/11 64 位
Microsoft Edge WebView2（Windows 11 通常已自带）
完整版安装不需要网络连接，安装后可直接离线识别和翻译。
不需要预先安装 Python，单文件安装器已内置隔离的 Python 3.12 运行时。

安装
----
推荐方式：从官方 GitHub Releases 下载并双击最新的 YiSheng-Setup-<版本>.exe，选择安装位置并等待文件解压完成；Base 和该版本支持的离线翻译模型随安装包提供，完成后桌面会出现带专属 Logo 的“Yisheng”快捷方式。
1.0.21 已内置韩语识别及翻译所需模型；正式版功能以对应 Release 为准。

资源要求
--------
四语言版安装时建议预留 2.5 GB 可用磁盘空间和至少 4 GB 运行内存。安装器会提前检查磁盘及运行内存；不足时会直接显示具体原因和需要释放的空间。
Base 识别模型和中、日、英、韩离线互译模型内置；韩中、韩日通过英语中转，可能丢失部分细节。正常使用不需要访问模型下载网站。启动后会在后台快速检查 GitHub 新版本；无法连接更新服务器时不影响当前版本使用。

如果拿到的是源码 ZIP：
1. 先把整个 ZIP 解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击“安装译声.cmd”。
3. 等待依赖和免费模型下载完成。
4. 双击 Yisheng.exe 启动。

使用
----
1. 选择原语言。
2. 选择声音来源：
   - 麦克风：听你说话。
   - 电脑声音：听游戏、视频、会议或直播。
   - 麦克风 + 电脑：同时监听两路声音。
3. 点击“开始同传”，再次点击停止。
4. 点击“导出文本”保存原文和中文翻译。

说明
----
所有实时音频只在本机处理，不调用付费语音或翻译 API。
如果电脑声音设备不正确，请在右上角设置中选择正在使用的扬声器或耳机。
默认使用性能均衡的 Base 模型；韩语对话可直接将原语言选为“韩语”，无需另外下载识别模型。
