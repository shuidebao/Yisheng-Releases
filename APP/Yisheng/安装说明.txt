译声 · 免费本地同声传译
========================

系统要求
--------
Windows 10/11 64 位
Microsoft Edge WebView2（Windows 11 通常已自带）
完整版安装不需要网络连接，安装后可直接离线识别和翻译。
不需要预先安装 Python，单文件安装器已内置隔离的 Python 3.12 运行时。

安装
----
推荐方式：从官方 GitHub Releases 下载并双击最新的 YiSheng-Setup-<版本>.exe，选择安装位置并等待文件解压完成；Base 和该版本支持的离线翻译模型随安装包提供，完成后桌面会出现带专属 Logo 的“Yisheng”快捷方式。
1.0.21 已内置韩语识别及翻译所需模型；正式版功能以对应 Release 为准。

如果收到的是 1.0.25 VR 实验测试包：请先退出旧版译声，再双击 YiSheng-Setup-1.0.25.exe 安装，通过桌面快捷方式或安装目录中的 Yisheng.exe 启动。此包用于外部头显测试，尚未完成真实头显验收，不代表已发布 GitHub 正式版或自动更新。旧 1.0.24 安装包不含 VR 功能。

资源要求
--------
四语言版安装时建议预留 2.5 GB 可用磁盘空间和至少 4 GB 运行内存。安装器会提前检查磁盘及运行内存；不足时会直接显示具体原因和需要释放的空间。
Base 识别模型和中、日、英、韩离线互译模型内置；韩中、韩日通过英语中转，可能丢失部分细节。正常使用不需要访问模型下载网站。启动后会在后台快速检查 GitHub 新版本；无法连接更新服务器时不影响当前版本使用。

如果拿到的是源码 ZIP：
1. 先把整个 ZIP 解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击“安装译声.cmd”。
3. 等待依赖和免费模型下载完成。
4. 双击 Yisheng.exe 启动。

使用
----
1. 选择原语言。
2. 选择声音来源：
   - 麦克风：听你说话。
   - 电脑声音：听游戏、视频、会议或直播。
   - 麦克风 + 电脑：同时监听两路声音。
3. 点击“开始同传”，再次点击停止。
4. 点击“导出文本”保存原文和中文翻译。

说明
----
所有实时音频只在本机处理，默认离线翻译，不需要 API。
1.0.23 可在设置中自选 API 文字翻译：停止同传，填写兼容 Chat Completions 的服务地址、模型名和密钥，确认文字发送及可能费用，再应用设置。只有主动启用后才发送识别文字，不上传语音。测试连接仅发送固定 Hello.，可能计费。
API 配置不保存到磁盘；切回本地清除后台密钥，重启默认本地。服务需用户自行提供，不内置密钥，不自动重试或切换；服务质量、隐私和费用请向服务方确认。
如果电脑声音设备不正确，请在右上角设置中选择正在使用的扬声器或耳机。
默认使用性能均衡的 Base 模型；韩语对话可直接将原语言选为“韩语”，无需另外下载识别模型。

VR 私人字幕（1.0.25 实验版）
---------------------------
面向 Windows + SteamVR + PC 版 VRChat，优先测试 Quest 有线和无线 PCVR。Quest 一体机直接运行 VRChat 不在本版范围；尚未确认各头显和连接软件的兼容性。
1. 建立 PCVR 连接，确认 SteamVR 已运行且识别头显，再启动 PC 版 VRChat。Quest 可先测 Steam Link，或有线 Link 后进入 SteamVR；其他连接方式同样需要实际经过 SteamVR。
2. 打开译声“设置 → VR 私人字幕 · 实验版”，点击“开启 VR 字幕”。连接成功后先点击“显示测试字幕（5 秒）”，在头显中确认文字可见、位置与样式合适。固定测试文字不启动录音、不调用 API；结束后恢复当前句，没有当前句时隐藏。
3. 选择 VRChat 正在使用的电脑声音输出设备和语言，点击“开始同传”。VR 只显示当前一句；新字幕或清空会提前结束测试字幕。
4. 停止同传后点击主界面“清空记录”，检查头显字幕消失，再开始同传检查新字幕。清空也会删除主界面记录，需要时请先导出。
5. 在 VR 设置中点击“关闭”，或正常退出译声，检查叠层消失。若提示进程尚未确认退出，再点“关闭”重试；关闭 VR 字幕不会停止同传。重启后 VR 默认关闭，位置与样式恢复默认。
6. 可选连续测试约 30 分钟，记录字幕停更、闪烁、明显卡顿、位置漂移或阅读不适；不舒服时立即停止。

VR 字幕不写入 VRChat 聊天框，也不经 OSC 发送给其他玩家；录屏、镜像或直播可能捕获本地叠层。默认免费离线，VR 开关不会启用 API；只有用户主动配置并明确同意后，可选 API 翻译才发送识别文字，不上传语音。
